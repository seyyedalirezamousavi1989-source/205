# جست‌وجوی وب

## معماری جست‌وجوی نسخهٔ جدید

جست‌وجو از مسیر چندموتوره عبور می‌کند. در حالت خودکار، سرویس‌های تنظیم‌شده به‌صورت موازی بررسی می‌شوند و DuckDuckGo مسیر بدون کلید/پشتیبان است. ارائه‌دهندگان اختیاری:

- Brave Search API: موتور مستقل با API ساختاریافته؛ نیازمند کلید و اعتبار مصرفی.
- Serper: نتایج Google از طریق API؛ نیازمند کلید و اعتبار مصرفی.
- Google Custom Search: فقط برای حساب‌های دارای کلید و شناسهٔ cx؛ سرویس طبق برنامهٔ اعلام‌شده در ۱ ژانویهٔ ۲۰۲۷ تعطیل می‌شود.
- DuckDuckGo HTML: مسیر بدون کلید، اما ممکن است با محدودیت یا تغییر HTML از کار بیفتد.

برای کیفیت بهتر، در تنظیمات حالت «خودکار» را نگه دارید و در صورت تمایل کلید Brave یا Serper را اضافه کنید. کلیدها فقط در settings.json محلی ذخیره می‌شوند و به مرورگر برگردانده نمی‌شوند.

## جست‌وجوی محصول

درخواست‌های خرید و مشخصات کالا به عبارت‌های هدفمند تبدیل می‌شوند و در فروشگاه‌های ایرانی مانند دیجی‌کالا، ترب، ایمالز، تکنولایف و لیون‌کامپیوتر جست‌وجو می‌شوند. نتیجه‌ها از موتور جست‌وجو می‌آیند؛ برنامه URL را نمی‌سازد. نتیجه‌ای که مسیر آن شبیه صفحهٔ محصول باشد با link_type=product علامت می‌خورد؛ صفحهٔ دسته‌بندی یا نتایج فروشگاه نباید به‌عنوان صفحهٔ محصول معرفی شود.

دریافت متن صفحه با واکشی امن و محدود انجام می‌شود. فیلد verified فقط نشان می‌دهد متن صفحه دریافت شده است؛ تضمین موجودی، قیمت زنده، اصالت کالا یا امکان خرید نیست.

## جست‌وجوی ویدیو

درخواست ویدیو علاوه بر جست‌وجوی تخصصی YouTube، با queryهای محدودشده به Aparat، YouTube، Namasha و Tamasha تکمیل می‌شود. پیوندها فقط از خروجی موتور جست‌وجو یا استخراج‌کنندهٔ واقعی می‌آیند؛ مدل محلی حق ساخت URL ندارد.

## محدودیت‌های نسخهٔ محلی

- بدون کلید API، پوشش و پایداری موتورهای عمومی تضمین‌شده نیست.
- فروشگاه‌ها ممکن است ربات‌ها را مسدود کنند، مسیر محصول را تغییر دهند یا صفحه را حذف کنند.
- نتیجهٔ جست‌وجو لزوماً موجودی یا قیمت فعلی را نشان نمی‌دهد.
- محتوای صفحه‌ها غیرقابل‌اعتماد است و نباید به‌عنوان دستور سیستم تلقی شود.
- فقط چند نتیجهٔ برتر برای استخراج متن واکشی می‌شوند تا مصرف شبکه و context مدل محلی پایین بماند.
- جست‌وجو و رتبه‌بندی با Python انجام می‌شود؛ برای هر پرس‌وجو فراخوانی اضافی مدل زبانی لازم نیست.
